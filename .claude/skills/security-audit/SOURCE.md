# Origine

Skill `security-audit` de Cloudflare, installée telle quelle (sans modification) depuis
https://github.com/cloudflare/security-audit-skill (licence MIT, voir LICENSE), commit c1c8a8c.

Usage : demander à l'agent « fais un audit de sécurité de ce dépôt » (audit complet : six phases, fichiers produits dans un dossier de sortie),
ou poser une question de sécurité ciblée (mode guidage, rien n'est écrit).
